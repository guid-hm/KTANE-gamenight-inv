# Keep Talking and Nobody Explodes — Date Night Invitation

A single-page invitation themed around the video game "Keep Talking and Nobody Explodes." No build step, no dependencies besides a Google Fonts CDN link.

## Before sending

1. **Set the date** — edit `index.html`, search for `date-placeholder`, replace the `DATE: TBD` text.
2. **Set the Google Meet link** — edit `script.js`, replace the `GOOGLE_MEET_URL` constant near the top of the file with the real meeting link.

## Running locally

Just open `index.html` in a browser. No server required.

## Deploying

Drag the folder into Netlify's deploy-drop UI, enable GitHub Pages on a repo containing these files, or add it as a static site on Render/Vercel — no build command needed, publish directory is the project root.
